# Handoff context: GHOSTNET: Deep Dive

Read this first if you are picking the project up. It says what the game is, what is done, how it is built, what to be careful about, and what is next.

## 1. What it is

A 2D launch-and-glide upgrade game (in the style of "Learn to Fly") set underwater, made for a competition by a student team, so **every script must be explainable to a jury**:
small, plain, well-named code with comments that say *why*. Built in **Godot 4.6.2, GDScript only, Compatibility renderer, no add-ons**, 1280x720, runs as a **Web export (threads off)**.

Story/message (SDG 14, Life Below Water): ghost nets from Port Halo's fleet trap sea life. Cleaning helps one animal at a time, but the problem only ends at the source, which is the **Net Return** upgrade (permanently fewer loose nets) and the results line **"You cut N nets. The fleet cut loose M while you were down."** These two things must never be cut.

Repo: https://github.com/NishaadG/ghostnet-deep-dive (public). Collaborator: VaradRane12.

## 2. Status

Everything below is built, committed, and the tests pass.

- Title screen, 3 save slots, settings, credits, pause menu, a STORY gallery to rewatch scenes.
- Cutscenes (`scripts/story.gd` holds all the text): intro (comic pages 1 to 3), a meeting scene that pauses the dive at each net wall,
  a scene after each wall is torn, the ending (pages 5 to 8), and a Net Return scene. Radio lines from Pip and Captain Vale during dives.
  The fleet tags escalate: Boat 11 (wall 1), a scratched "Boat 0_" (wall 2), then BOAT 07 · CAPT. VALE on the Lumen.
- The dive: ramp launch, air arc, underwater flight model, boost, oxygen timer, floor/ceiling collision, camera, zones (Reef, Drowned City, Slope, Trench, Abyss).
- Nets (with trapped animals), pickups along glide arcs, plastic, Pip the drone, 4 persistent net walls (HP saved between dives), the whale ending, Endless mode.
- Workshop (shop): 3 gear slots with 6 named tiers each (Craft, Booster, Cutter), 5 tuning upgrades, Net Return ("Port Halo" tab), live rig preview, journey/wall progress.
- Art: **100% drawn in code** in a neon vector style. No sprite files are used in the game.
- Audio: kit sound effects plus two original music loops generated by `tools/make_music.py`; Music/SFX volume sliders and ON/OFF switches.
- Phones: landscape only, touch controls (top half tilt up, bottom half tilt down, BOOST, pause), "turn your phone" notice in portrait.
- Web export and itch.io package (`docs/ITCH.md`). Economy tuned with a headless simulation.

## 2b. Evaluation system (branch `feature/evaluation`)

Style points and ranks, in `scripts/style_score.gd` (scoring rules, ranks, tag bonus) fed by `Player` signals (`landed`, `flipped`, `looped`, `grind_ended`) and `Run` (net chain, canyon/drop zones from `Terrain.trick_zones`). The air only exists near the start (the cave ceiling closes it), so flips/airtime are launch-only; the launch ramp is a ski-jump curve (`Balance.ramp_point`) to give about a second of airtime. Underwater tricks are loops (hold nose-up at speed), floor grinds, canyon/drop clears and net chains. All numbers are in `balance.gd` (section "Tricks"). The results screen shows an EVALUATION panel; `Game.best_style` / `best_rank` are saved per slot. Tests: `tests/style.tscn`.

## 2c. Debug mode (branch `feature/debug-mode`)

`autoload/debug.gd` + `ui/debug_panel.gd`, opened with F9. Hooks are tiny: `Player` checks `Debug.is_on("god" / "oxygen" / "fuel")`, `Run._hit_wall` checks `"wall_kill"`, and `Run.debug_teleport / debug_spawn` do the moving. Set `Debug.ENABLED := false` for a release without cheats. Test: `tests/debug_mode.tscn`.

## 3. Decisions the user made (do not undo)

- Look: **neon vector, glowing**, everything procedural. The kit's AI-looking sprites and story images were deliberately dropped (they remain in `assets/` and `comic_assets/` for the comic only).
- Characters/dialogue: originally a middle ground (3-card intro and ending). **Later the user asked for real cutscenes and a deeper story**:
  drawn-in-code scenes with Captain Vale, Ilo the deckhand and the harbourmaster as standing figures (no detailed portraits).
- Gear: Learn-to-Fly style tiers with underwater names (not "glider"): Kickboard to Leviathan, Flipper Pump to Torpedo Drive, Wire Snips to Reef Saw.
- Length target: about **25 to 35 dives** to finish the story. First dive earns 8 to 15 tags. Wall 1 around dive 5. Money was originally far too easy, so keep it scarce.
- The user is short on time and prefers you decide small things yourself and report afterward.

## 4. How to run, test, build

```
godot --path . (or open project.godot and press F5)
godot --headless --path . --import                       # rebuild the class cache after adding scripts
godot --headless --path . res://tests/smoke.tscn          # a bot flies a real run
godot --headless --path . res://tests/progression.tscn    # upgrades, slots, saves, screens build
godot --headless --path . res://tests/economy.tscn -- clumsy=0.5 runs=2   # balance simulation (about 25 s per run)
godot --headless --path . res://tests/zones.tscn          # how far the bot gets with fixed kits and no walls
godot --headless --path . --export-release Web build/web/index.html
```
Screenshots (needs a real window, not headless): `godot --path . res://tests/menu_shot.tscn --write-movie out.png --fixed-fps 30 --quit-after 60 -- screen=workshop` (also `title`, `slots`, `results`, `gallery`, `settings`, `pause`, and `cutscene scene=intro beat=3` for any beat of any scene; add `tab=1` or `tab=2` for the workshop tabs). `res://tests/shots.tscn ... -- x=17000 touch` flies the bot from a chosen distance (x is metres times ten) and `res://tests/rigshot.tscn` shows every gear tier. Read the PNGs: it is the only way to judge visuals without a human.

Debug keys (also in the web build): F1 reset slot, F2 +500 tags, F3 mid-game save, F4 unlock Endless.

Tests write to throwaway files (`Game.save_dir = "user://test_"`, `Game.save_enabled = false`); never let a test touch the real `save_N.json`.

## 6. Tuning knobs (all in `balance.gd`)

- Feel: `GRAVITY`, `WING_TURN`, `DRAG`, `DRAG_MISALIGN`, `TILT_RATE`, `LAUNCH_SPEED`.
- Economy: `COST_SCALE` (all prices), `TAG_METRES` (metres per tag), `UPGRADE_COSTS`, `WALLS` (HP and bonus), `WALL_DAMAGE_SCALE`.
- After changing economy numbers, run `economy.tscn` at `clumsy=0.3, 0.6, 0.9` and check the story finishes in roughly 25 to 40 dives and wall 1 falls near dive 5.

## 7. Gotchas that cost time (learned the hard way)

- Godot **autoloads are not visible to `--script` SceneTree scripts**; headless tests are scenes (`.tscn` with a script) instead.
- GDScript treats **"inferred type from Variant" as an error** in this project: write `var x: float = dict["k"]` when the source is a Dictionary or untyped call.
- **Label autowrap**: set `autowrap_mode` **before** `size`, otherwise the label keeps its one-line width and text overflows.
- `TextureRect`: set `expand_mode` before `size`.
- Control screens added under a plain `Node` get size 0: set `size = Vector2(1280, 720)` explicitly.
- **2D MSAA is not supported by the Compatibility (GLES3) renderer**, so there is no anti-aliasing setting; lines use the `antialiased` flag instead.
- Polygon triangulation can fail on zero-area shapes; terrain and gradients use `draw_primitive` quads for that reason.
- Chrome automation can get a tab stuck after a long run; open a fresh tab rather than concluding the game froze.
- When the editor rewrites `project.godot` it drops default keys; that is harmless.
- Add a new script, then run `--import` so `class_name` types resolve.

## 8. Known issues and ideas for next steps

- Touch controls and phone layout are checked by code and screenshots only, **not on a real phone**. Test tap targets and performance on a weak device first.
- Music and sound were never heard by the author of this code, only measured (levels, loop seams). Ask someone to listen and adjust `tools/make_music.py` and `Audio.MUSIC_DB`.
- The diver is small on screen during a dive; consider a larger `body_scale` or a camera zoom tweak.
- The test bot is better than most people. Real players are probably slower, so ask for finish times and nudge `COST_SCALE`.
- Pip's level 3 arrow (to the next O2) is implemented but not play-tested.
- Endless mode is unlocked after the Lumen is freed; its late-game balance (drops grow 5% every 500 m, extra upgrade levels cost 1.6x) has not been simulated.
- The whale-freed slow motion was only tested by simulation. The cutscenes are checked by tests and screenshots; ask someone to read
  them all once (F5 unlocks every scene in the STORY screen) and trim any line that drags.
- Saves on itch.io live in browser storage (cleared with site data).
